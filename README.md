# کلینیک روان‌شناسی سپهر آرامش — صفحه‌ی اصلی

صفحه‌ی اصلی فارسی (RTL) با HTML5، CSS3 و جاوااسکریپت خالص. پایه‌ی بصری آن سیستم طراحی **«فیروزه»** از VibeFarsi است (در رجیستری با slug `turquoise`).

## اجرای محلی

بدون نیاز به build یا نصب پکیج:

```bash
cd sepehr-clinic
python3 -m http.server 8080
# سپس باز کنید: http://localhost:8080
```

باز کردن مستقیم `index.html` در مرورگر هم کار می‌کند.

## ساختار

```
sepehr-clinic/
├── index.html          ساختار معنایی، آیکون‌ها (sprite درون‌خطی) و همه‌ی بخش‌ها
├── css/styles.css      توکن‌های فیروزه + استایل‌ها (بخش‌بندی‌شده با فهرست در ابتدای فایل)
├── js/config.js        تنظیمات: نشانی پنل رزرو و پیوندهای حقوقی
├── js/script.js        ماژول‌های Nav / Split / Stream / Reveal / Accordion / Config
├── assets/
│   ├── fonts/          فایل‌های فونت (باید اضافه شوند؛ پایین را ببینید)
│   ├── images/         تصاویر تیم و ...
│   └── icons/
└── README.md
```

## کارهایی که باید انجام شود

### ۱. فونت‌ها (لازم برای ظاهر نهایی)

محیطی که این پروژه در آن ساخته شد به رجیستری npm دسترسی نداشت، پس **فایل‌های فونت همراه پروژه نیستند**. تا آن زمان صفحه با فونت‌های نصب‌شده‌ی سیستم و Tahoma نمایش داده می‌شود (خوانا است، اما ظاهر نهایی نیست).

1. این دو فونت (هر دو با مجوز آزاد) را دانلود کنید:
   - **Vazirmatn** (متن) — فایل variable با فرمت `woff2`
   - **Noto Kufi Arabic** (تیترها؛ فونت تیتر رسمی تم فیروزه) — فایل variable با فرمت `woff2`
2. آن‌ها را با این نام‌ها در `assets/fonts/` بگذارید:
   - `Vazirmatn-Variable.woff2`
   - `NotoKufiArabic-Variable.woff2`
3. در `css/styles.css`، بخش «2. FONTS»، خط‌های کامنت‌شده‌ی `src: url(...)` را فعال کنید و خط‌های `src: local(...)` را با آن‌ها جایگزین (یا کنار آن‌ها نگه‌دارید).

### ۲. نشانی پنل رزرو

در `js/config.js` مقدار `bookingUrl` را بگذارید. همه‌ی دکمه‌های «رزرو نوبت» (`data-link="booking"`) خودکار به آن متصل می‌شوند. تا زمانی که خالی باشد، یک یادداشت «تنظیم نشده» در بخش رزرو نمایش داده می‌شود. هیچ نشانی ساختگی در پروژه وجود ندارد.

`privacyUrl` و `termsUrl` هم در همین فایل‌اند و تا مقداردهی نشوند در فوتر ظاهر نمی‌شوند.

### نقشه‌ی داخل صفحه (اختیاری)
نقشه‌ی داخل صفحه از نقشه‌ی «نشان» می‌آید (`mapEmbedUrl`). برای تغییر آن، از کد iframe فقط مقدار `src` را بردارید و جایگزین کنید. فقط نشانی‌هایی که با `https://neshan.org/maps/iframe/` یا `https://www.google.com/maps/embed` شروع شوند پذیرفته می‌شوند.

### صفحه‌ی بلاگ (`blog.html`)
یک مطلب شاخص و شش کارت مطلب با عنوان، خلاصه، دسته، تاریخ شمسی و زمان مطالعه. **همه‌ی مطالب نمونه‌اند**، و دکمه‌ی «ادامه‌ی مطلب» عمداً غیرفعال است تا صفحه‌ی تک‌مطلب ساخته شود (در وردپرس به `the_permalink()` وصل می‌شود).
- **تصویر کاورها:** شش‌تا تصویر انتزاعی هم‌رنگ فیروزه‌اند که خودم ساخته‌ام، نه عکس واقعی: `assets/images/blog/post-1.webp` تا `post-7.webp`. برای عکس واقعی، فایل را با همان نام و نسبت ۸:۵ (مثلاً ۱۲۰۰×۷۵۰) جایگزین کنید و در `blog.html` برای `<img>` متن `alt` بنویسید.
- **عنوان و خلاصه:** مستقیم در `blog.html` ویرایش می‌شوند. هر کارت یک `<article>` است و در وردپرس به یک حلقه‌ی `WP_Query` تبدیل می‌شود.

### ۳. محتوای نمونه

هر جایی که محتوا موقت است، با نشان زرد «نمونه» یا «جایگزین شود» مشخص شده است:
- معرفی تیم (نام، عنوان، تصویر، تحصیلات، شماره‌ی پروانه) — همه نمونه‌اند و هیچ فرد واقعی‌ای درج نشده است. برای تصویر، در `index.html` کامنت `<img>` زیر هر `.member__photo` را فعال کنید.
- نشانی، تلفن، ساعت کاری، ایمیل و نقشه در بخش تماس و فوتر.
- متن‌های سوالات متداول درباره‌ی هزینه، مدت جلسه و سیاست لغو نوبت.

## آنچه از VibeFarsi گرفته شده و چگونه تطبیق داده شده

VibeFarsi کتابخانه‌ی React + Tailwind v4 است؛ این پروژه طبق خواسته به HTML/CSS/JS خالص برگردانده شده است.

| منبع (رجیستری) | در این پروژه |
|---|---|
| تم `turquoise` (فیروزه) | همه‌ی توکن‌ها عیناً به‌صورت CSS custom property در `:root` (رنگ، شعاع، عمق، حرکت، بلور، `--backdrop`) |
| `card` | کلاس `.card` (سطح شیشه‌ای با blur و هایلایت درونی) |
| `button` | کلاس‌های `.btn` (shape/depth/press از توکن‌ها) |
| `accordion` | سوالات متداول (شورون، انیمیشن ارتفاع با `grid-template-rows`، `aria-expanded`/`aria-controls`) |
| `hero` | الهام برای شبکه‌ی محو (`.cta::before`)؛ چیدمان هیرو مستقل است |
| `highlight-text` | `.hl` (خط ماژیکی که از راست کشیده می‌شود) |
| `streaming-text` | `.stream` / `.sw` (کلمه‌ها از دل تاری، با نقطه‌ی سر جریان) |
| `gradient-text` | `.gradient-text` در بخش رزرو |
| `grain` | بافت دانه روی کل صفحه (`body::after`) |
| `persian-ui-copy` | راهنمای نگارش متن‌های رابط (واژه‌نامه، لحن، ZWNJ) |

مستقل از VibeFarsi پیاده‌سازی شده‌اند: انیمیشن کلمه‌به‌کلمه‌ی تیتر هیرو، reveal با IntersectionObserver، گوی هیرو و کارت‌های شناور، حرکت آرام aurora، منوی موبایل، چیدمان‌ها.

## منابع بیرونی

- **هیچ منبع بیرونی لازم نیست.** هیچ CDN، اسکریپت ردیابی یا کتابخانه‌ای بارگذاری نمی‌شود.
- آیکون‌ها SVG درون‌خطی در `index.html` هستند. این آیکون‌ها **دست‌نویس و به سبک Lucide** هستند، نه خود Lucide (دسترسی به npm نبود). اگر خواستید، می‌توانید هر `<symbol>` را با SVG رسمی Lucide جایگزین کنید.
- فونت‌ها: بالا را ببینید.

## نکات برای تبدیل به قالب وردپرس

- `css/styles.css` و `js/script.js` فایل‌های مستقل‌اند و فقط با `wp_enqueue_style` / `wp_enqueue_script` بارگذاری می‌شوند.
- تمام رنگ و فاصله و حرکت از CSS variable می‌آید؛ تغییر ظاهر فقط در بخش ۱ فایل CSS است.
- `js/config.js` را می‌توان با `wp_localize_script` جایگزین کرد (شیء `window.SEPEHR_CONFIG`).
- منو، بخش‌ها و کارت‌ها به‌سادگی به `wp_nav_menu` و حلقه‌ی پست (برای تیم و خدمات) قابل تبدیل‌اند.
- اسکریپت کوچک ابتدای `<head>` (کلاس `js` و failsafe) را در `header.php` نگه دارید.

## دسترس‌پذیری و حرکت

- `prefers-reduced-motion: reduce` همه‌ی انیمیشن‌ها را خاموش و محتوا را کامل نمایش می‌دهد.
- بدون JavaScript، همه‌ی محتوا قابل خواندن است (انیمیشن‌ها فقط با کلاس `js` فعال می‌شوند). اگر `script.js` بارگذاری نشود، بعد از ۴ ثانیه failsafe همه‌چیز را نشان می‌دهد.
- فوکوس قابل‌مشاهده، پیوند «پرش به محتوا»، ناوبری با کیبورد (منو: Esc؛ آکاردئون: ↑ ↓ Home End).


## صفحه‌ی گالری و برنامه‌ها (`gallery.html`)

- دو فیلتر: **وضعیت** (پیش‌رو / برگزارشده) و **نوع** (همه، گروه‌درمانی، کارگاه عمومی، کارگاه تخصصی). بدون JavaScript هر دو بخش یکی پس از دیگری نمایش داده می‌شوند.
- دکمه‌های «مشاهده» در کارت‌های صفحه‌ی اصلی با پیوند مستقیم باز می‌شوند: `gallery.html#group`، `#public`، `#specialized` (و برای وضعیت: `#public-past`، `#group-upcoming`).
- **پیش‌رو:** برنامه‌هایی که کلینیک تعریف می‌کند؛ ثبت‌نام با تماس تلفنی. فعلاً سه کارت نمونه است (`.program`). در وردپرس مناسب‌ترین شکل، یک custom post type به نام «برنامه» با فیلدهای نوع، تاریخ و ظرفیت است.
- **برگزارشده:** تصاویر در `assets/images/gallery/` (فعلاً ۶ تصویر انتزاعی نمونه)؛ با کلیک در `<dialog>` بزرگ می‌شوند. برای افزودن مورد جدید یک `li.shot` با `data-type` مناسب اضافه کنید.
- **افتخارات و مدارک** (`#honors`): سه قاب جایگزین برای مجوزها، افتخارات و مدارک؛ پس از دریافت فایل‌ها `.doc__frame` را با `<img>` عوض کنید.
- همه‌ی موارد این صفحه با نشان «نمونه» مشخص شده‌اند.

## تغییرات محتوایی اخیر

- نشان و تیتر هیرو، کارت‌های خدمات (۵ کارت اصلی + ۳ کارت گروه‌درمانی و کارگاه‌ها)، بخش تیم و سیاست لغو (در سوالات متداول) به‌روز شدند.
- از ۷ پیوند ناوبری، منوی موبایل از عرض ۶۴rem به پایین فعال می‌شود (هم در CSS و هم در `isMobile` در `script.js`).
